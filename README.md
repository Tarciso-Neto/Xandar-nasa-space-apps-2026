# Xandar | NASA Space Apps Challenge 2026 🚀

**Repositório de documentação e preparação da equipe Xandar** para o **NASA Space Apps Challenge 2026 — edição Vitória da Conquista (BA)**.

Este espaço reúne materiais de consulta, pesquisas e referências organizados **antes da definição e do desenvolvimento do projeto**. Seu objetivo é facilitar o acesso da equipe às informações necessárias para tomar decisões fundamentadas durante a preparação para o hackathon.

> **Importante:** este **não é o repositório de desenvolvimento do projeto**. O código-fonte, as implementações e os entregáveis técnicos serão organizados pelo líder técnico em um repositório próprio, separado deste acervo.

## 📚 Documentos disponíveis

| Documento | Conteúdo | Acesso |
|---|---|---|
| **Regulamento do NASA Space Apps Challenge 2026** | Regras de participação, entregas, licenças, critérios e cuidados para a competição, incluindo informações sobre a edição local. | [Ler regulamento](./REGULAMENTO_NASA_SPACE_APPS_CHALLENGE_2026.md) |
| **Catálogo de Tecnologias e Ferramentas** | Ferramentas de programação, inteligência artificial, dados científicos, matemática, visualização, design, hospedagem, APIs, bancos de dados e outros recursos para apoiar a futura escolha da solução. | [Consultar catálogo](./CATALOGO_TECNOLOGIAS_E_FERRAMENTAS_NASA_2026.md) |

## 🎯 Para que serve este repositório?

- **Centralizar informações** relevantes para a preparação da equipe.
- **Facilitar a consulta** às regras e exigências da competição.
- **Comparar ferramentas e tecnologias** antes de escolher a arquitetura do projeto.
- **Registrar pesquisas e decisões preparatórias**, preservando as respectivas fontes.
- **Compartilhar materiais** de forma simples entre os integrantes, inclusive pelo celular.

## 🧭 Como utilizar este acervo

1. Leia o **regulamento** antes de decidir como executar ou apresentar uma solução.
2. Consulte o **catálogo** quando precisar identificar ferramentas adequadas a determinada atividade.
3. Confira **licenças, disponibilidade gratuita, limites de uso e fontes oficiais** antes de adotar um recurso.
4. Utilize este repositório como material de apoio; decisões de implementação e código devem ser documentados no futuro repositório técnico.

## 📌 Escopo e atualizações

Este acervo é **preparatório e informativo**. Novos documentos poderão ser incluídos conforme a equipe analisar os desafios e organizar sua participação. Informações sobre preços, limites de planos, APIs, licenças e regulamentos podem mudar; sempre confirme os requisitos atuais nas fontes oficiais.
